# AWS Deadline Cloud for KeyShot

The KeyShot submitter for AWS Deadline Cloud is now a sample in the
[deadline-cloud-samples](https://github.com/aws-deadline/deadline-cloud-samples) repository:
[job_bundles/custom_submitters/keyshot](https://github.com/aws-deadline/deadline-cloud-samples/tree/mainline/job_bundles/custom_submitters/keyshot).

Use the sample for installation, worker setup, and the latest code. To build the KeyShot conda package that
workers use, see the
[KeyShot 2025 conda recipe](https://github.com/aws-deadline/deadline-cloud-samples/tree/mainline/conda_recipes/keyshot-2025).

This repository is no longer updated.
